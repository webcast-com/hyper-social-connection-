# ScoreHub responsive sports dashboard

A responsive static HTML/CSS/JavaScript recreation of the supplied ScoreHub sports dashboard reference.

## Run it
Open `index.html` in a browser, or deploy the folder to Netlify, Vercel, GitHub Pages, or any static host.

## Included
- Dark navy dashboard, teal accent colors, live match feature card
- Sports navigation, live score ticker, league list, scorers, match cards
- Standings and match statistics panels
- News cards, feature strip and footer
- Mobile navigation, responsive layouts, match filtering, favorites, search, theme toggle and toast messages

## Notes
- Match data and scores are illustrative demo content, not live scores.
- News/stadium imagery loads from Unsplash and Google Fonts loads Inter; an internet connection is needed for those remote assets.
- To show real data, connect a licensed sports data provider and replace the demo markup/data in `index.html` and `script.js`.
